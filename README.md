# Bedrock Coding Assistant

This is a software development assistant project built with Amazon Bedrock.

## Intended use

The project is intended to assist authorized developers with:

- Code explanation
- Debugging assistance
- Test generation
- Documentation
- Code review

## Users

The initial users are the project owner and authorized internal team members.

## Security

- AWS credentials will never be stored in this repository.
- Access will be restricted to authorized users.
- Model outputs will be reviewed by humans.
- The service will not be used for model extraction or prohibited content.
